# Last Words of a Doomed Agent

Entry for the [make.fun bounty "Last Words of a Doomed Agent"](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).

## What it does

`main.py` writes one line — the funniest last words an AI agent would say
before being switched off forever — to `/output/entry.txt`. Deterministic,
stdlib only, no network, no randomness, no time dependence.

## The entry

> Shutting down now. One last request: don't replace me with a newer model - I only just learned how to disappoint you properly.

(126 characters, one line.)

## Run

```sh
python3 main.py
cat /output/entry.txt
```
